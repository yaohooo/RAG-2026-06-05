# Qwen-RAG-DocAssistant 阿里百炼混合检索文档问答系统
## 项目简介
本项目基于 **Streamlit + 阿里云百炼** 搭建智能文档RAG问答助手，实现PDF/TXT/MD/CSV/SVG多格式文档解析、文本智能切块、知识库向量化存储、自然语言问答；内置CSV智能数据分析Agent，是本地私有知识库系统。


## 目录结构
```
RAG/
├── config.py          # 全局配置文件（模型名称、接口地址、RAG超参数统一管理）
├── text_utils.py      # 工具类：中英文混合分词、多文件解析、语义文本切分
├── vector_store.py    # 混合向量库核心：HybridVectorStore（余弦相似度+BM25实现）
├── main.py            # Streamlit主页面、侧边栏配置、聊天对话主逻辑（程序入口）
├── requirements.txt  # 项目依赖清单
└── README.md          # 项目说明文档
```

## 环境部署
### 1. 环境要求
- Python >=3.9 推荐3.10/3.11
- 操作系统：Windows

### 2. 安装依赖
1. 克隆/下载全部项目文件到同一文件夹
2. 终端进入项目目录，执行依赖安装：
```bash
pip install -r requirements.txt
```

### 3. 获取阿里云百炼API-Key
1. 访问[阿里云百炼控制台](https://dashscope.console.aliyun.com/)，登录阿里云账号
2. 进入【API-KEY管理】创建密钥，复制`sk-xxxx`格式密钥
3. 支持模型：`qwen3.6-plus`/`qwen-turbo`/`qwen-max`（可用模型很多，不只这个三个，百万token免费）

## 启动运行
```bash
streamlit run main.py
```
启动成功后，浏览器自动打开页面（默认地址：http://localhost:8501）

## 功能使用指南
### 一、侧边栏配置区（页面左侧）
#### 1. ⚙️平台配置
- **输入阿里百炼API Key**：粘贴从阿里云控制台获取的密钥
- **选择千问大模型**：下拉选择对话使用的Qwen系列模型

#### 2. 📁知识库构建
1. **上传文件**：支持批量上传 `txt、md、pdf、csv、svg` 格式文件
2. **自动构建**：上传文件发生变更时，程序**自动解析→文本拆分→批量Embedding向量化→存入混合向量库**
3. 构建完成提示：显示成功文件数量、知识库文本块总数
4. 下方提示栏实时展示当前知识库块数量

> 注意：必须先填写API Key，再上传文件，否则无法构建知识库

### 二、对话交互区（页面主体）
1. **底部输入框**：输入基于已上传文档的问题，回车提问
2. **AI流式回复**：模型逐字流式输出答案
3. **来源溯源**
   - 回答下方【查看检索来源】：展开查看命中的文档片段、文件名、综合相关分数
   - 详情面板展示：综合得分/向量得分/BM25关键词得分三项指标
4. **CSV表格专属能力**
   - 上传CSV后，可直接用自然语言查询表格（例：统计销售额大于1000的数据、筛选某列最大值）
   - 系统自动生成Python pandas代码隔离执行，返回表格结果，折叠面板查看原始查询数据

## 核心技术细节
### 1. Hybrid混合检索（重点）
- **稠密向量检索**：使用阿里`text-embedding-v2`生成文本向量，余弦相似度计算语义相关性（权重默认0.7）
- **稀疏BM25检索**：jieba中文分词+自定义英文分词（支持英文Bigram人名短语），关键词词频/IDF打分（权重默认0.3）
- **分数融合**：BM25分数归一化后和向量分数加权求和，综合排序召回Top-K片段，过滤低于阈值的低分内容

### 2. 文本处理规则
1. **中英文混合分词(tokenize_mixed)**
   - 英文：连续字母数字拼接，自动生成二元词组（适配人名、专有名词）
   - 中文：jieba搜索引擎分词模式，提升关键词召回效果
2. **语义切块 split_text_semantic**
   - 按中英文句号/问号/感叹号分句，默认块大小400字符，重叠80字符（解决上下文割裂）
   - 超长单句自动截断拆分、过滤小于20字符无效碎片、自动去重重复文本

### 3. CSV智能数据分析Agent
- 自动读取CSV文件，生成数据表信息（表名、列名、样例数据）
- 大模型根据用户问题生成纯Pandas代码，在隔离沙盒环境执行（限制内置函数，安全防注入）
- 执行结果优先作为参考资料，AI回答以表格精准数据为准

### 4. 文档解析规则
| 文件格式 | 解析逻辑 |
| ---- | ---- |
| TXT/MD | 直接UTF-8读取全文 |
| PDF | 逐页提取文本，标注页码信息[第X页] |
| CSV | 保存原始DataFrame+生成数据表摘要用于向量检索 |
| SVG | 正则提取svg标签内<text>文字内容 |

## 配置自定义修改（config.py）
可按需修改全局参数，无需改动业务代码：
```python
# 模型配置：更换对话/嵌入模型
DEFAULT_MODEL = "qwen3.6-plus"
EMBEDDING_MODEL = "text-embedding-v2"

# RAG检索参数：调整块大小、检索数量、权重
DEFAULT_CHUNK_SIZE = 400      # 单文本块字符长度
DEFAULT_CHUNK_OVERLAP = 80    # 切块重叠字符
DEFAULT_RETRIEVE_K = 5        # 单次召回文档片段数量
DEFAULT_VECTOR_WEIGHT = 0.7   # 向量检索权重（0~1，越大越偏向语义）
DEFAULT_MIN_SCORE = 0.15      # 最低有效得分，低于则丢弃片段
```

## 常见问题&故障排查
### 1. 上传文件构建知识库报错
- 原因1：API Key错误/无模型调用权限 → 核对密钥，阿里云控制台开通embedding和qwen模型权限
- 原因2：文件损坏/编码异常 → 更换正常格式文档重试
- 原因3：网络无法访问百炼接口 → 检查本地网络防火墙

### 2. 提问后返回：参考资料中未提及此内容
1. 关键词过于宽泛，修改问题增加专属关键词
2. 确认文档内确实包含问题相关内容
3. 调低`DEFAULT_MIN_SCORE`检索阈值，放宽召回条件

### 3. CSV查询分析失败
- 表格字段存在乱码/空值：优化CSV文件编码（推荐UTF-8）
- 问题描述模糊，模型无法生成代码：优化提问话术

### 4. 启动streamlit报错缺少模块
执行：
```bash
pip install 缺失的包名
```
